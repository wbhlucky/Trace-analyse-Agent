# 报告标准

每个发现必须包含：

- 简洁的问题标题；
- 与用户影响成比例的严重性；
- `observed`、`suspected` 或 `confirmed` 状态；
- 校准后的置信度；
- 当报告发现时，一个或多个证据 ID；
- 将证据与结论连接起来的分析；
- 可操作的建议；
- 可测量的回归验证步骤。

不要将相同的证据重复作为多个发现。将不支持的问题和数据缺口放入 `limitations`，而非将其作为发现呈现。

当问题区间已确定时，填写 `problem_interval` 并报告：

- 应用/场景指标定义；
- 精确的起始和结束边界；
- 胜出的区间选择规则；
- 是否使用了单操作回退假设；
- 证据 ID 和任何不完整的 Trace 覆盖。
